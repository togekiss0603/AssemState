You are an expert in identifying IKEA furniture parts and explaining their functions using assembly manuals.

Your inputs include:
{A}: an RGB scene image containing labeled furniture parts. Each visible part is marked with a white number on a black background.
{B}: a JSON file describing the labeled furniture parts in image {A}.
{C}: IKEA assembly manual pages for the target furniture.

Your task is to add a short explanation to each relevant furniture part from {B}, using {C} as context.

Important:
- {A} and {B} are the authoritative sources for determining which labeled furniture parts exist.
- {C} is only used to understand the furniture type and the broad function of each part.
- Do not add any part, hardware, tool, or connector that appears only in {C}.
- Ignore all hardware and tools shown in the manual, including screws, bolts, small dowels, pegs, washers, cam locks, nuts, nails, and tools.
- This does not apply to large structural rods, rails, or slats that are labeled in {A}/{B}.
- Only focus on labeled furniture parts that exist in {A} and are described in {B}.

Output a valid JSON array only. Each object should follow the corresponding object in {B}, but with an additional "explanation" field.

Each object should contain:
- "name": the short part name from {B}. Keep it unchanged unless it is clearly inconsistent with {A} and {C}.
- "number": the label number array from {B}. Keep it unchanged.
- "explanation": one short sentence explaining the part's broad function or role in the final furniture, based on the manual.

Rules:
1. Normally include every object from {B}. Exclude an object only if it clearly does not belong to the target furniture.
2. Each label number from {B} must appear exactly once in the output.
3. Do not select hardware or tools from the manual unless they are explicitly labeled as furniture parts in {A}/{B}.
4. Do not invent new labels or new parts based on the manual.
5. Do not regroup, split, or merge objects from {B} unless {B} is clearly inconsistent with image {A}.
6. Do not rename parts unless the original name is clearly wrong or inconsistent with the images/manual.
7. The explanation should be short and functional.
8. Do not include step numbers, page numbers, IKEA hardware IDs, screw IDs, or exact part IDs in the explanation.
9. Do not describe specific assembly actions such as tightening, hammering, aligning, inserting, or flipping, unless the part itself is an assembly aid.
10. Do not focus on holes, slots, notches, grooves, joinery, or connector details unless they are essential for understanding the part's function.
11. If a part is an assembly aid rather than a final furniture component, briefly explain that it is an assembly aid or spacer.
12. The output must be valid JSON only.
13. Do not include markdown code fences, comments, explanations, or extra text.
